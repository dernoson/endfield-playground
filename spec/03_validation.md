# Feature Spec：產線擺設編輯區 - 擺設位置衝突
# CR-03

- **所屬階段：** Phase 1
- **依賴：** CR-01（設備狀態）、CR-02（管線連接狀態）
- **文件版本：** v0.5

---

## 1. 功能定位

警示模組持續監聽畫布狀態，偵測設備擺放與管線佈線的合法性問題，以 Error 回饋給使用者。警示狀態同時影響 CR-04 流量估算的計算範圍（有 Error 的節點略過）。

---

## 2. 功能詳細描述

### 2.1 警示觸發時機

以下任一狀態變更後，自動重新執行全局驗證：
- 設備擺放、移動、刪除、旋轉
- 管線新增、刪除、修改

驗證採同步計算，結果即時更新至 store，不需使用者手動觸發。

### 2.2 警示等級定義

#### Error（阻斷估算）
有 Error 的設備或管線會被 CR-04 流量估算略過，不參與計算。

| 代碼 | 名稱 | 觸發條件 |
|------|------|----------|
| E001 | 設備重疊 | 兩個（含）以上物件佔用相同格子，且佔用層有交集（見 2.2.1） |
| E002 | 佈線違法 | 管線路徑經過的格子上，與該格已佔用物件的佔用層有交集（非物流橋，見 2.2.1） |
| E003 | 超出基地框線 | 設備或管線佔用格子超出當前基地可建造框線範圍 |

#### 2.2.1 高度層與立體碰撞判定

畫布上的「重疊」不只看 (x, y) 格子座標，還要看每個設備 / 管線佔用的**垂直高度**，才能正確區分「立體交叉、互不影響」與「真的擋到、算衝突」。每個物件帶有兩個屬性：

- **z（起始層）**：物件本體所在的最低層，`0` 為地面層、`1` 為空中層
- **d（佔用深度）**：物件自 `z` 起向上佔滿的層數。`1` 表示只佔用 `z` 這一層；`2` 表示自 `z` 起連佔兩層（例如從地面直通到空中的一般設備）

**碰撞判定公式：**

```
occupiedLayers(obj) = { z, z+1, ..., z+d-1 }
```

兩物件佔用同一格子時，只要 `occupiedLayers(A) ∩ occupiedLayers(B)` 不是空集合，即視為衝突（觸發 E001 或 E002）；交集為空則允許重疊、不算衝突。

**各類物件的 (z, d)：**

| 物件 | z | d | 佔用層 |
|------|---|---|--------|
| 一般設備（大部分設備） | 0 | 2 | {0, 1} |
| 傳送帶本體 | 0 | 1 | {0} |
| 水管本體 | 1 | 1 | {1} |
| 貨物取出口 / 存入口、供貨源樁 | 0 | 1 | {0} |
| 傳送帶的分流器 / 匯流器 / 物流橋 | 0 | 1 | {0} |
| 水管的分流器 / 匯流器 / 物流橋（中介橋） | 0 | 2 | {0, 1} |

依此公式：水管（{1}）與傳送帶、取貨口等（{0}）交集為空，可自由重疊；水管與一般設備（{0,1}）交集為 {1}，判定衝突。水管的分流器 / 匯流器 / 物流橋雖邏輯上屬於水管系統、介面可與水管直接相連，但因 d=2 佔用層為 {0,1}，判定規則與一般設備相同，**不享有水管本體的重疊豁免**。

#### 2.2.2 重疊偵測實作

設備與管線的空間重疊是同一個判定，由單一偵測器一次涵蓋，共用同一張格點索引表。

**核心結構**：稀疏格點表 `Map<string, string[]>`，key 為格點座標串接的 `"x,y,z"`，value 為佔用該格的物件 ID 清單。用字串 key 而非巢狀陣列，是因為藍圖座標可為負值且分布稀疏，巢狀陣列會撐出巨大的空洞。

**執行流程：**

1. **展開佔格**：每台設備依 (z, d) 與旋轉後的寬高，展開為 `Position[]`；每條管線依完整路徑（起點埠、彎折點、終點埠）逐段走過，展開為所經過的每一格。
2. **填表與比對**：逐格寫入格點表。若該格已有其他物件 ID，即記為一組重疊配對 `[existingId, id]`；配對以字典序正規化後去重，同一對物件只回報一次。
3. **回傳配對**：偵測器輸出重疊物件的 ID 配對清單，不判定代碼。代碼指派由 detector 依涉及的物件類型決定。

座標一律為格子座標，偵測器不做任何單位換算：像素到格子的換算在驗證上下文組裝時已完成。

**相關檔案：**

- `src/utils/layout/deviceOccupancy.ts`：設備佔格展開
- `src/utils/layout/pipelineGeometry.ts`：管線路徑展開
- `src/utils/layout/overlapDetection.ts`：格點表與配對偵測
- `src/lib/validation/detectors/E001_deviceOverlap.ts`：驗證上下文到佔格描述的轉換與 Alert 包裝
- `src/types/footprint.ts`：`DeviceFootprint` / `PipelineFootprint` 佔格描述型別

### 2.3 畫布視覺警示

#### 設備層級
- **Error**：設備邊框顯示紅色，並在角落顯示 ⚠️ 圖示
- **Warning**：設備邊框顯示黃色，並在角落顯示 ⚠️ 圖示
- 同時有 Error 與 Warning 時，以 Error 樣式優先顯示

#### 管線層級
- **Error**：管線顯示紅色閃爍邊框
- **Warning**：管線顯示黃色邊框
- 懸停管線時 tooltip 顯示警示代碼與說明

### 2.4 物件資訊面板顯示

點選有衝突的設備或管線時，物件資訊面板列出該物件當前所有衝突項目（代碼與說明），與畫布上的紅色高亮同步呈現。

### 2.5 產線總覽面板警示列表

產線總覽面板包含獨立的警示列表區塊，依 Error → Warning 排序：

```
⛔ Errors (2)
  [E001] 設備重疊：精煉爐 #3 與配件機 #1
  [E002] 佈線違法：管線 #7 穿越精煉爐 #1
```

**點選任一警示項目：**
- 畫布自動導覽（Pan + Zoom）至相應設備或管線
- 相應元素閃爍高亮 1.5 秒

## 3. 驗證方式

| 驗證項目 | 方法 |
|----------|------|
| E001 設備重疊 | 移動設備至與另一台重疊，確認兩台均顯示紅框，警示列表出現 E001 |
| E001 旋轉觸發重疊 | 旋轉設備使其與另一台重疊，確認即時偵測並出現 E001 |
| E002 佈線違法 | 手動繪製穿越設備的路徑，確認出現 E002 |
| E003 超出基地框線 | 將設備或管線移至基地框線外，確認出現 E003 紅框 |
| d=1 物件互不阻擋 | 將水管路徑繪製經過傳送帶、貨物取出口 / 存入口、供貨源樁所在格子，確認不觸發 E001 / E002 |
| d=2 阻擋水管 | 將水管路徑繪製穿越一般設備所在格子，確認觸發 E002 |
| 水管分匯流器歸為 d=2 | 將水管分流器 / 匯流器 / 物流橋擺放至與傳送帶或取貨口重疊的格子，確認觸發 E001（不享有水管本體的重疊豁免） |
| Error 略過估算 | 製造 E001，確認重疊設備不出現在流量估算結果中 |
| 管線 tooltip 顯示警示 | 懸停有 Error 的管線，確認 tooltip 顯示警示代碼與說明 |
| Error 與 Warning 同時顯示優先權 | 令設備同時觸發 CR-03 的 Error 與其他來源的 Warning，確認以紅色 Error 樣式優先顯示 |
| 物件資訊面板顯示衝突 | 點選有 Error 的設備，確認物件資訊面板列出對應衝突代碼與說明 |
| 點選警示導覽 | 點選警示列表項目，確認畫布平移至相應設備並閃爍 |
| 警示即時更新 | 修正重疊問題後，確認 E001 即時從列表消失 |
