# 步驟 04｜正式頁手動驗收

本步透過正式頁驗證完整資料流，可搭配既有 Story 檢查空列表與顏色。只有需要補接線測試時才調整既有的 `docs/toby/test/layoutFlowWiring.test.ts`。依 A.12，若修改該測試檔，另執行 `pnpm exec prettier --check docs/toby/test/`。

| 操作 | 預期結果 |
| --- | --- |
| 讓兩台設備重疊，再移開 | 右欄出現並移除 E001 訊息。重疊期間兩台設備皆標紅。 |
| 放置需要輸出的設備，補接輸出 | 缺輸出時顯示 E005 並標紅。補接後 E005 清除。 |
| 同一台設備觸發多筆警示，只修正其中一筆 | 保留其餘提示與紅色，最後一筆解除才恢復原色。 |
| 清空畫布或解除全部警示 | Tips 列表留空，畫布無警示標紅。 |
| 操作正常產線的連線，或解除影響產線的 Error | 產耗依現有規則重算，警示解除後恢復可估算的產線結果。 |

案例通過後，進入[品質與交付](./W1109-T1_alerts_step_05_quality_gate.md)。目前尚未執行。
