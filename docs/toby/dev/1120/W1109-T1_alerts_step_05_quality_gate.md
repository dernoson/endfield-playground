# 步驟 05｜品質檢查與交付

- **目標** ：確認差異限於核准範圍，並完成 PR 的驗收紀錄。
- **檔案** ：檢視最終 diff 及實際改動檔案。新增 SFC 宣告需要的註解依 A.3 使用繁中 JSDoc。
- **檢查** ：依 A.6 執行 `pnpm type-check`、`pnpm lint-check`、`pnpm format-check`、`pnpm test`。交付時記錄實際變更、手動案例、指令結果與仍待解決的上游問題。
- **交付** ：實作與驗收完成且可提交時，依步驟 01 確認的基準更新 #84，或在其合併後另開僅含警示的 PR。推送與 PR 操作依使用者明確指示進行。
- **完成條件** ：正式頁的顯示與解除案例、既有產耗回歸、品質檢查皆通過，PR 範圍核對完成。
