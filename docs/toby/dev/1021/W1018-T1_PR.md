# 正式畫布支援埠連線與設備旋轉

正式畫布原先只能拖設備與平移，無法從埠建立管線。現在一般左鍵會優先命中埠，顯示本地 draft 與目標 highlight，放開時使用 canConnect、端點身分比對及既有碰撞檢查驗證，再透過 addPipeline 提交一次。非法路徑改紅色預覽，放開後清除並顯示非彈窗回饋。

draft 僅存在 LayoutView 的 local ref，取消、失去捕捉與卸載皆清理；埠幾何與機型映射由 L2 轉成 props，GridCanvas 只呈現埠點、預覽與狀態文字。保留設備拖曳、空白／中鍵／pan 平移及連續落子，新增程式附繁體中文 JSDoc，顏色使用 Tailwind 內建色階。

斷線端點由既有 layoutStore.connections 判定，透過 props 掛上其他作者提供的 WarningIcon，重新接回即清除。依使用者要求，埠命中只限可見圓點，取消附近熱區；GridCanvas.stories.ts 維持 Git 基準內容。

已放置設備可在選取後以預設 R 鍵順時針旋轉 90 度，並支援既有鍵位設定。layoutStore 的高階旋轉 action 自行建立歷史、檢查重疊，管線保留原位；MainLayout 與 LayoutView 共用同一個選取 id，旋轉後尺寸、埠及斷線警示同步更新。文字輸入及拖曳時不觸發旋轉。

## 範圍

優先使用直線與單一明確正交轉角；原路徑只穿過端點設備時，可採設備間空隙的固定雙轉角，不搜尋繞開其他設備或既有線的路徑。未使用相鄰直線降級備案。後續旋轉需求新增 layoutStore.rotateDevice 與 MainLayout 單選 props 接線，既有方法簽名及命中／連線規則維持原狀；C3 管線樣式與 DeviceShape 掛載保留後續處理，未修改他人 shapes。
