## 3. 建議演示產線（待實操核定）

沿 D5 §4.2：源 → 加工 → 匯出點，3 台；固體（belt）；單入單出；兩台刻意錯開一格，強制一個 90 度彎。

| 角色 | 候選 `Machine.id` | 依據 | 待核 |
|------|-------------------|------|------|
| 源 | `material_source`（基礎材料輸出點） | `is_source: true`；`sourceMaterialOptions` 可選基礎材料；固體型態輸出走 belt | 固體型態的輸出口位置、能選哪些固體材料 |
| 加工 | `crusher`（粉碎機）候選 | 3×3；單入單出的機率高 | 配方是否單一輸入單一輸出；輸入材料是否與源可選材料相符 |
| 匯出點 | `item_sink`（物品輸入口）或 `warehouse_input`（倉庫存貨口） | `is_sink: true` | 哪個在引擎裡算 `sinkDeliveries`；是否出現在工具列 |

核定方式（C1 實作時做）：

1. 從 `src/data/machines.ts`／`products.ts` 找「單入單出、固體」的配方，確認源的材料能餵進去
2. 用 `/dev/flow-engine` 或 `layoutStore` 測試先驗引擎讀得到（只當查證，不當演示）
3. 在正式頁照表擺一次，記下三台座標、旋轉、材料，寫進 D5 附錄
4. 核定前不凍結。若找不到符合的組合，如實記錄，不為了劇本改資料

凍結後換產線視為改版本號（D5 §4.2）。
